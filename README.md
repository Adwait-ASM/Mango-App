# Kher Farm Website

## Overview
A responsive website for Kher Farm, showcasing Alphonso mangoes from Ratnagiri, Maharashtra.

## Features
- Mango-themed design
- Responsive layout
- Contact form
- Sections highlighting farm and product

## Setup
1. Clone the repository
2. Open `index.html` in a web browser
